# 📝 Dynamisk Bloggplattform

En enkel webbapplikation där användare kan skapa och publicera blogginlägg – helt dynamiskt med HTML, CSS och JavaScript. Inga omladdningar krävs när nya inlägg skapas.

---

## 🚀 Funktionalitet

- 🏠 **Startsida** – visar alla befintliga och nya blogginlägg
- ✍️ **Skapa inlägg** – användarformulär för titel och innehåll
- 🔁 **Dynamisk visning** – nya inlägg visas direkt på sidan
- 📱 **Responsiv design** – fungerar på både dator, surfplatta och mobil
